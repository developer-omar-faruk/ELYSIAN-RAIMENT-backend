# Elysian-Raiment backend

Express 4 + MongoDB (Mongoose) API for the existing `my-project` storefront and admin panel. It sits beside `my-project/` and does not touch it.

## Database indexes

On startup, the backend creates indexes declared by its Mongoose models without dropping existing indexes. Remove or replace obsolete indexes through a reviewed database migration.
